Apresentação comercial da Carus MKT para a nova loja Vanessa Fernandes no Pioneiros, em Balneário Camboriú (inauguração em 03/10/2026).

Página estática em um único arquivo (HTML + CSS + JS, imagens embutidas), sem etapa de build. Pronta para GitHub Pages.

- `index.html` — apresentação (13 telas; no celular vira página rolável)
- `robots.txt` + meta `noindex` — a página não deve aparecer em buscadores
